# Grupo Shefa — sitio web

Sitio corporativo en Astro 5 + Tailwind (salida estática). Es un sitio web de Hernán: aplica la skill `website-creator` (20 puntos) y se publica en su Vercel Pro. Datos del sitio en `src/data/sitio.js`; landings de empresas en `src/pages/[empresa].astro`.

## Agent skills

### Issue tracker

GitHub Issues del repo `hernaneem/gruposhefa` vía `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context (`CONTEXT.md` y `docs/adr/` en la raíz). See `docs/agents/domain.md`.
